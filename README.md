# Task 1 — Student Result Processor

## Description
A plain JavaScript application that calculates student results,
ranks students, and prints a class report.

## Features
- Calculates total marks and percentage.
- Assigns grades and PASS/FAIL status.
- Ranks students by percentage.
- Displays the class average, topper, and failed students.
- Finds the topper in every subject.
- Validates marks outside the 0–100 range.
- Displays a result table in the browser.
- Verifies that the original student data remains unchanged.

## Files
- `index.html` — Loads the JavaScript module.
- `data.js` — Exports the student data.
- `utils.js` — Exports reusable helper functions.
- `main.js` — Calculates and displays the report.

## Concepts Practised
let, const, arrow functions, template literals, destructuring,
spread, default parameters, Object.values, Object.entries,
Object.keys, map, filter, reduce, sort, find, every, some,
and ES modules.

## How to Run
1. Open this folder in VS Code.
2. Start the Live Server extension using `index.html`.
3. Open the browser developer tools with F12.
4. Select the Console tab to see the report.
