# Task 2: Todo App

I created a Todo App using HTML, CSS, and JavaScript.

### Features
- Add, edit, and delete tasks.
- Mark tasks as completed.
- Filter tasks by All, Active, and Completed.
- Save tasks in localStorage.
- Tasks remain saved after refreshing the page.

### Technologies
HTML, CSS, JavaScript, DOM, and localStorage.

### How to Run
Run `npx live-server .` in the terminal and open the browser link.
